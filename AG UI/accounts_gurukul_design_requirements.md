# PRD: Accounts Gurukul Website & Admin Panel

## Brand Overview
- **Name:** Accounts Gurukul
- **Location:** Siliguri, India
- **Target Audience:** Class 11, 12, B.Com, CA Foundation students and parents.
- **Primary Goal:** Student admissions via WhatsApp and Phone calls.

## Design Principles
- **Style:** Minimal, clean, professional, trust-building.
- **Colors:** Primary: #1E3A8A (Dark Blue), Accent: #22C55E (WhatsApp Green), Background: White, Text: Dark Gray.
- **Priority:** Mobile-first, thumb-friendly, fast-loading.

## Page Structure (Landing Page)
1. **Hero:** Headline, Subheadline, Primary CTA (WhatsApp), Secondary CTA (Call), Trust Badges.
2. **Trust Section:** Experience, Student Count, Faculty stats.
3. **Courses:** Cards for Class 11, 12, B.Com, CA Foundation with "Join via WhatsApp" CTAs.
4. **Why Choose Us:** Key differentiators (small batches, personal attention, etc.).
5. **Results/Testimonials:** Student success stories with images.
6. **About Teacher:** Image, experience, and teaching style.
7. **Gallery:** Grid of classroom and student images.
8. **Contact:** Google Map, clickable phone, WhatsApp button, address.
9. **Global:** Sticky navbar, floating WhatsApp button, bottom sticky CTA.

## Admin Panel Features
1. **Login:** Secure access.
2. **Result Management:** Upload student name, marks, and images.
3. **Testimonials:** Manage feedback and photos.
4. **Gallery Management:** Multi-image upload, preview, and delete.
5. **Course Management:** Edit details.
6. **Image Upload System:** Local device upload UI with preview and progress indicators.
